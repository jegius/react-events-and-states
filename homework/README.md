# Global Chat Homework

Учебное React-приложение "Глобальный чат", реализованное с использованием React и Redux Toolkit.

## Функциональность

В приложении реализовано:

* регистрация пользователя;
* авторизация пользователя;
* выход из аккаунта;
* просмотр общего чата;
* отправка сообщений в общий чат;
* получение сообщений с backend API;
* сохранение текущего пользователя, токена и сообщений в localStorage;
* восстановление состояния приложения после перезагрузки страницы;
* кеширование сообщений на уровне Redux state;
* виртуальный скролл для списка сообщений через React Context.

## Технологии

* React
* Redux Toolkit
* React Redux

## Backend API

Backend находится в папке:

```text
homework-backend
```

Сервер запускается на:

```text
http://localhost:3001
```

Используемые endpoints:

```text
POST /register
POST /login
GET /chats
POST /chats
```

Для запросов к `/chats` используется JWT-токен в заголовке:

```text
Authorization: Bearer <token>
```

## Запуск backend

Перейти в папку backend:

```bash
cd homework/homework-backend
```

Установить зависимости:

```bash
npm install
```

Запустить сервер:

```bash
npm start
```

После запуска сервер будет доступен по адресу:

```text
http://localhost:3001
```

## Запуск frontend

Перейти в папку frontend:

```bash
cd homework
```

Установить зависимости:

```bash
npm install
```

Запустить приложение:

```bash
npm start
```

Если порт `3000` уже занят, можно согласиться на запуск на другом порту.

## Структура frontend

Основные части приложения:

```text
src/api
src/app
src/components
src/context
src/features/auth
src/features/chat
```

### `src/api`

Содержит функции для работы с backend API:

* регистрация;
* логин;
* получение сообщений;
* отправка сообщений.

### `src/app`

Содержит настройку Redux store и логику сохранения состояния в localStorage.

### `src/features/auth`

Содержит Redux slice для авторизации:

* регистрация;
* логин;
* logout;
* хранение username и token.

### `src/features/chat`

Содержит Redux slice для сообщений:

* загрузка сообщений;
* отправка сообщений;
* хранение сообщений;
* хранение статусов загрузки.

### `src/components`

Содержит компоненты интерфейса:

* `AuthPage`;
* `ChatPage`;
* `MessageList`;
* `MessageItem`;
* `MessageInput`;
* `VirtualScroll`.

### `src/context`

Содержит React Context для настройки Virtual Scroll.

## Сохранение состояния

Состояние приложения сохраняется в localStorage под ключом:

```text
global-chat-state
```

Сохраняются:

* текущий пользователь;
* JWT-токен;
* сообщения;
* время последней загрузки сообщений.

После перезагрузки страницы приложение восстанавливает сохранённое состояние.

## Кеширование

Сообщения сохраняются в Redux state и localStorage. При инициализации приложения сохранённые сообщения подгружаются из localStorage, поэтому пользователь сразу видит предыдущие данные без ожидания нового запроса.

При открытии страницы чата приложение также делает актуальный запрос к серверу, чтобы обновить список сообщений.

## Virtual Scroll

Для списка сообщений реализован компонент `VirtualScroll`.

Он использует React Context для настроек:

* высота одного элемента;
* количество дополнительных элементов сверху и снизу видимой области.

Это позволяет не рендерить сразу весь список сообщений, если сообщений становится много.
