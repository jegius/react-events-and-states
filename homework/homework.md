# Как я сделал проект "Глобальный чат"

В этом файле я описал, как устроено моё приложение, какой функционал в нём работает и как его запустить для проверки.

---

## Что я сделал в проекте

### 1. Вход и регистрация пользователей
*   **Регистрация**: Сделал форму, которая отправляет данные на сервер по адресу `/register`. Сервер проверяет, свободен ли логин (`username`), шифрует пароль и создаёт аккаунт. После этого приложение само переключает пользователя на форму входа.
*   **Вход в систему**: Форма отправляет данные на `/login`. Если всё верно, сервер выдаёт секретный ключ (JWT-токен). Этот ключ приложение использует, чтобы подтвердить, что пользователь авторизован.
*   **Защита данных**: Все запросы к чату закрыты проверкой на сервере. Без правильного ключа в заголовке сообщения прочитать или отправить не получится.

### 2. Работа чата и отправка сообщений
*   **Загрузка истории**: Как только пользователь успешно входит в систему, приложение сразу запрашивает с сервера все старые сообщения по адресу `/chats` и выводит их на экран.
*   **Отправка сообщений**: Когда мы пишем текст и нажимаем кнопку, данные уходят на сервер в поле `body`. Если отправка прошла успешно, новое сообщение сразу добавляется в конец списка чата.
*   **Общий доступ**: Все сообщения хранятся в одной базе на сервере. Поэтому если зайти с другого аккаунта, будут видны сообщения остальных пользователей с их именами.

### 3. Сохранение сессии (Кэширование)
*   Чтобы пользователю не приходилось вводить пароль заново при каждой перезагрузке страницы, я настроил сохранение данных. 
*   Секретный ключ и логин автоматически записываются в память браузера (`LocalStorage`).
*   При обновлении страницы приложение проверяет эту память: если ключ там есть, чат открывается сразу. При нажатии на кнопку «Выйти» память полностью очищается в целях безопасности.

### 4. Умный скролл для защиты от зависаний (Virtual Scroll)
*   Для плавного отображения длинного списка сообщений я написал свой компонент виртуализации списка — `VirtualList`.
*   Он следит за тем, в каком месте чата находится пользователь, и загружает в код страницы только те сообщения, которые видны на экране прямо сейчас (плюс парочку сверху и снизу для плавности).
*   Остальные тысячи сообщений просто имитируются по высоте. Благодаря этому браузер вообще не тормозит, даже если в чате будет 10 000 сообщений.
